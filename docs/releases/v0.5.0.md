# rat v0.5.0 release notes

Release scope: Go CLI and the built-in kernels since `v0.4.0`.

This release makes R and Julia notebooks as dependable as Python ones,
keeps rich output (interactive charts, widgets) in its place, records
the exact versions a project's notebooks run with, and opens rat to any
Jupyter kernel. Notebook clients check `rat version --json`
(`"notebook_api": 2`) for all of it.

## Highlights

- **R and Julia kernels that behave like their consoles.** Output
  streams as it is printed; `readline()` asks whoever runs the cell;
  cancel interrupts the running code and keeps every variable (a second
  cancel, 3 s later, stops code that ignores the interrupt); no time
  limit on a cell. R prints every visible value, reports warnings and
  errors in R's words with the calls that led to them, and keeps each
  plot page. Julia's cells behave as its REPL (`;`, `ans`), with no
  package needed by the kernel.
- **`rat jl` is Julia's own REPL** — modes, history, Unicode completion
  — evaluating in the shared kernel, with Tab completing from it and
  Ctrl-C interrupting it.
- **Rich displays.** An interactive page (plotly, htmlwidgets, PlotlyJS),
  an SVG or an image is announced in its place among the output
  (`__RAT_DISPLAY__:<bundle>`, Jupyter's display_data). Python's
  `display()` and plotly's `fig.show()`, R's widgets and Julia's HTML
  displays all produce them.
- **Exact completion.** Kernels say which text a completion replaces
  (`rat look --code … --json` → `{start, matches}`): R's `data.frame`,
  `df$col` and `pkg::fun` complete in place.
- **Packages and lock files.** `rat.r.dependencies` and
  `rat.julia.dependencies` beside `rat.python.dependencies`, installed by
  a script of the language itself (rat's core knows no language), and
  locks committed with the project — `.rat/python.lock`, `.rat/r.lock`,
  `.rat/julia/Manifest.toml` — that `rat ensure` reproduces on the next
  machine. `rat ensure --update` resolves again.
- **`rat guide py|r|jl`**: how to install the language on this
  computer, for a person or their AI, as it is. rat also finds a runtime
  where its installer put it (juliaup, R's folders) before a new shell
  has it on the PATH.
- **Any Jupyter kernel** as a rat runtime (`kernel.type: jupyter`), through
  rat's own client of Jupyter's protocol — no Python needed.

## Also

- Requests carry ids; a late reply to a request that gave up is dropped.
- On Windows, Python cells can be interrupted (a message to the kernel's
  reader thread) instead of stopping the kernel.
- A kernel that dies is replaced by the next request, with what it
  printed in the error; restart works while a cell hangs.

## Upgrading

Restart running kernels to get the new ones (`rat restart r`, `rat
restart jl`). Notebooks need nothing: a lock is written by the next
`rat ensure`.
